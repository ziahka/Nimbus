# Nimbus Changelog

## ☁️ Nimbus 1.1.0

### 🔐 Security pass

 - **Module source is now HTTPS-only.** Whatever `.dlmod <url>` fetches is executed as
   Python, so over plain HTTP anyone on the network path could rewrite it in flight and
   own the account. `RemoteStorage.fetch` now refuses non-TLS URLs outright
   (`InsecureModuleSourceError`), with a localized error in all 9 langpacks
   (`loader.insecure_url`). The same rule applies to the repo *listing* (`full.txt`) —
   which is worse if unprotected, since it decides which files get installed at all —
   in `_get_repo`, `.dlmall` and `get_repo_list`
 - **`.presets` no longer installs third-party code.** It used to be a hardcoded table of
   ~56 links into other people's GitHub accounts and `mods.kok.gay`: one tap installed
   mutable, unaudited code with full access to your Telegram account, from repos the
   Nimbus owner has no relationship with and cannot pin. Presets are now named by module
   and resolved at runtime against `.config Loader MODULES_REPO` — this fork's own
   catalog by default — so a preset can never reach outside a repo you already trust
 - **Repo credentials are no longer handed to arbitrary hosts.** `.dlmod
   https://evil.example/x.py` previously sent your configured `basic_auth` along with the
   request; it's now scoped to URLs that actually live under a configured repo
 - **Stopped leaking your Telegram user ID.** Every module download sent an
   `X-Nimbus-User: <your tg id>` header to whatever host was serving the file. Removed
 - **Tokens now come from a CSPRNG.** `utils.rand()` feeds inline callback data, unit ids
   and pending-command tokens — all guessable when generated by Mersenne Twister. Now
   backed by `secrets`
 - **`utils.check_url` is an allowlist.** It used to accept any scheme with a netloc, so
   `file://`, `ftp://` and `gopher://` passed validation into config values and download
   paths. Now `http`/`https` only, with callers that legitimately need more (`tg://`
   deep links on inline buttons) passing them in explicitly
 - **Dropped third-party image hotlinks.** The inline `.terminal` cards pulled banners
   from x0.at — an anonymous, ephemeral file host whose images can be swapped or expire
   at any time — and the inline help entries hotlinked an icon CDN. Both told a stranger's
   server your host IP and exactly when you use your userbot. Both removed

### ✨ New modules

 - Added `.neofetch` (`.sys`) — a neofetch-style card for the machine Nimbus runs on:
   OS, kernel, Python/Nimbus versions, uptime, core count, process RSS, and live
   CPU/RAM/disk bars. Fully re-skinnable via `.config SysInfo custom_template`
   (20 placeholders) and `.config SysInfo bar_width`
 - Added `.chatstat` (`.cstat`) — message statistics for the current chat: a bar-chart
   leaderboard of the top posters with medals and percentages, a media breakdown by type,
   and a 24-hour activity sparkline with the busiest hour. Configurable via
   `.config Stats default_limit` / `top_size` / `bar_width`
 - Added `.whois` (`.wi`) — a detailed card for any user, chat or channel (argument,
   reply, or the current chat): ID, username, phone, language, common chats, status and
   bio for users; member/online/admin/banned counts and description for chats, plus
   verified / premium / scam / fake / restricted badges
 - Added `textfx` to the module catalog — `.type` (typewriter animation), `.mock`,
   `.flip`, `.wide`, `.bubble`, `.spaced`
 - Added `nimbus/utils/render.py`, shared card-drawing helpers now available to every
   module as `utils.progress_bar`, `utils.humanize_bytes`, `utils.humanize_number` and
   `utils.sparkline`

### 💻 Evaluator

 - `.e` gained a much larger namespace: `chat_id`, `me`, and `asyncio`, `datetime`,
   `json`, `os`, `random`, `re`, `sys`, `time`, `typing` — the things a one-liner in a
   chat always ends up needing
 - Added eight more languages: `.ets` (TypeScript/deno), `.ephp`, `.eruby` (`.erb`),
   `.elua`, `.eperl` (`.epl`), `.ejava`, `.ehs` (Haskell), `.esh` (`.ebash`)
 - Added `.ebf` — a Brainf*ck interpreter with a step budget, and `.esql` — SQL against
   a throwaway in-memory SQLite database, rendered as a table. Neither needs anything
   installed. (`.ebf` was already advertised in every langpack but had never existed)
 - Added `.elangs` — which toolchains are actually present on this machine
 - `.ec` was compiling **C++**: it wrote the source to `code.cpp` and handed it to
   `gcc`, which picks the language from the file extension. It writes `code.c` now
 - Every `.e*` language now falls back to the replied-to message for its code — before,
   only `.ers` and `.eg` did
 - Compiler and interpreter output is now run through the same secret redaction `.e`
   uses, so a `print(process.env)` in Node can't leak your bot token into a chat
 - Compiling and running no longer block the event loop. A 30-second compile used to
   freeze every other command, watcher and inline handler along with it
 - Timeouts now say so instead of showing an empty output block

### 🐛 Fixes

 - Inline forms, lists and galleries passed `reply_to` to `Message.edit`, which does not
   accept it — so the "Opening form…" status raised `TypeError` on *every* outgoing
   command and was silently swallowed. It works now, and failures are logged
 - The command message that opened a form/list/gallery is now reliably deleted:
   `Message.delete()` resolves the message's input chat first and fails outright when
   that entity isn't cached, which left commands like `.cfg` sitting in the chat next to
   the form they opened. It now retries by `peer_id` and logs if that fails too
 - `store_asset` passed `message_thread_id` to `send_message`, which has no such
   parameter — saving any non-`Message` asset raised `TypeError`. It's `reply_to`, as
   the sibling branch two lines up already had it
 - Fixed four translations whose placeholders no longer matched the code, each an
   `IndexError` at runtime for anyone on that language: `updater.ub_stop` (de, ua) and
   `loader.modules_unloaded` / `loader.modules_not_unloaded` (de)

## ☁️ Nimbus 1.0.0

 - Added a built-in chat/group moderation module: `.ban` / `.unban` / `.kick` / `.mute` /
   `.unmute` / `.promote` / `.restrict` / `.admins` / `.bots` / `.users` / `.flush` /
   `.owns` / `.inspect` / `.id` / `.rights` / `.dnd` / `.invite` / `.create` / `.leave` /
   `.pin` / `.unpin` / `.dgc` / `.requests` — ships loaded by default, no `.dlmod` needed.
   Commands ported from `chatmodule.py` by codrago ([@codrago_m](https://t.me/codrago_m),
   https://github.com/coddrago/modules) and adapted for this fork: imports rewritten for
   `nimbustl`, and the original's runtime dependency on a remotely-fetched library
   (`xdlib.py`, pulled live from `coddrago/modules` on every startup) has been inlined
   locally instead, so the module no longer talks to any third-party server
 - Security re-audit: reconfirmed the previous hardening pass is intact (HTTP timeouts,
   no shell string execution, no live third-party code fetch anywhere in core) and
   extended it to the new moderation module (no `eval`/`exec`/shell calls, no unescaped
   dynamic imports)
 - `.gitignore`: added a dedicated secrets/credentials section (`*.pem`, `*.key`,
   `*.crt`, `.env.*`, `secrets.json`/`.yml`/`.yaml`, `credentials.json`) and removed a
   duplicate `*.mp3` entry
 - `.nimbus` now supports a fully custom card via `.config Settings custom_template`
   (placeholders: `{version}`, `{major}`, `{minor}`, `{patch}`, `{build_url}`,
   `{library}`, `{ping}`, `{uptime}`, `{status_line}`, `{branch}`, plus any module-
   registered custom placeholder) — leave it empty to keep the built-in localized card
 - `.help` now supports a custom header line via `.config Help header_template`
   (placeholders: `{count}`, `{hidden}`)
 - (`.ping` and `.info` already had this exact full-template mechanism from before —
   `.config Tester custom_message` and `.config NimbusInfo custom_message` respectively;
   no changes needed there, documented here for discoverability)
 - Documented the new moderation commands in `README.md` / `README_RU.md`
 - Fixed `patched_import` in `nimbus/loader.py` not redirecting `herokutl` imports to
   the vendored `nimbustl` the way `hikkatl`/`telethon` already were — third-party
   modules that `import herokutl` directly were silently loading a real, unrelated
   PyPI package of that name instead of this fork's own client library

## ☁️ Nimbus 2.5.0

 - Added `.afk` / `.unafk` — auto-replies while you're away, with per-chat cooldown and
   automatic turn-off on your next outgoing message
 - Added `.save` / `.note` (`.n`) / `.notes` / `.delnote` — saved text snippets you can
   recall by name
 - Added `.remind` / `.reminders` / `.delremind` — self-reminders on a delay
   (`10m`, `2h`, `1d2h30m`, ...), restart-safe
 - Removed the `.ask` smart command router and the `.tldr` AI summary command —
   dropped the built-in dependency on an external AI provider
 - `.dlmod` / `.dlm <name>` now installs from this repo's own [`modules/`](modules/)
   catalog by default, instead of the original Heroku maintainer's module repo
 - Added a first batch of catalog modules: `.broadcast` (+ `.bcadd`/`.bcdel`/`.bclist`),
   `.purge`, `.calc`
 - Added [`DEVELOPING.md`](DEVELOPING.md), a guide for writing and submitting modules
 - Rebuilt `.nimbus`'s output template (all 9 langpacks): dropped a leftover
   "Developers: @ur_jump" credit line pointing at the original Hikka project's contact
   that had survived the entire rebrand, fixed a nonsensical 📁 icon on the library
   version line, and restyled it into one boxed card with ping/uptime
 - Restyled `.info` with the same closing tagline treatment
 - Both cards' tagline is configurable (`.config Settings status_line`,
   `.config NimbusInfo status_line`)
 - Redrawn all 12 banner images (`assets/*.png`) with a glowing dusk-sky cloud scene —
   soft rim lighting, stars, a moon, sparkle accents — generated procedurally via
   [`tools/generate_banners.py`](tools/generate_banners.py) (Pillow + numpy, run through
   `uv run --with pillow --with numpy`)
 - Upgraded several plain emoji to premium/custom Telegram emoji across `.notes`,
   `.remind`, `.broadcast`, and the `.nimbus` card, reusing emoji IDs already verified
   elsewhere in this codebase
 - Security pass: dropped every `.presets` entry hosted on `codrago.life` (including a
   file literally named `DoxTool.py`) and the remaining `coddrago/modules` links
   (one named `hardspam.py`) — these were third-party-controlled, mutable, unaudited
   code that Nimbus offered to install with one tap
 - Added a `timeout=` to every outgoing `requests.get` call that was missing one
   (module downloads, avatar fetch, library fetch, language pack fetch) — an
   unresponsive remote host could previously hang the request indefinitely
 - Replaced a `os.system(f"cd {...} && ...")` shell string in the hard-update path with
   the same argv-list `subprocess.run(...)` form used everywhere else in that file
